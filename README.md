## 🚀 Публикация сайта (раскрытие в интернет)

Чтобы сайт стал доступен **всем по публичной ссылке**, его нужно опубликовать.

### Шаг 1. Откройте диалог публикации
- **На десктопе:** кнопка **Publish** в правом верхнем углу редактора.
- **На мобильном:** кнопка в правом нижнем углу в режиме Preview.

### Шаг 2. Нажмите «Publish» (первая публикация)
После первой публикации сайт получит постоянный адрес вида:

> **https://ai-automation-glue.lovable.app**

(это уже текущий публичный адрес проекта)

### Шаг 3. Обновление сайта
После любых изменений во **фронтенде** (вёрстка, стили, тексты) нужно
снова открыть диалог Publish и нажать **Update** — изменения станут
доступны на публичной ссылке.

> ⚠️ Изменения в **бэкенде** (edge-функции, миграции БД) деплоятся
> автоматически и не требуют ручного обновления.

### Шаг 4. Проверка видимости
Убедитесь, что в настройках публикации выбрано **Public** —
тогда ссылку сможет открыть любой человек без входа в Lovable.

## 🌐 Подключение собственного домена

Перед подключением домена сайт **должен быть опубликован**.

1. Перейдите в **Project Settings → Domains**
   *(или в диалоге Publish → Add custom domain)*.
2. Введите ваш домен (например, `terpeneva.ru`).
3. Добавьте указанные DNS-записи у регистратора домена
   (обычно `A` и/или `CNAME`).
4. Дождитесь проверки DNS и автоматической выдачи SSL-сертификата
   (обычно от нескольких минут до часа).

После этого сайт будет открываться по вашему домену с HTTPS.

📖 Подробнее: https://docs.lovable.dev

## 🔗 Поделиться превью без публикации

Если нужно показать сайт **до** официальной публикации:

1. Нажмите **Share → Share preview** в редакторе.
2. Скопируйте созданную ссылку.
3. Ссылка работает **7 дней** и доступна без аккаунта Lovable.

> Это режим «только просмотр» — отличается от публикации тем, что
> ссылка временная.

## 💻 Локальный запуск

Если вы выгрузили код из Lovable (через GitHub) и хотите запустить
проект у себя:

```bash
# Установка зависимостей (рекомендуется bun)
bun install

# Запуск dev-сервера
bun run dev

# Сборка production-версии
bun run build
```

После `bun run dev` сайт будет доступен на `http://localhost:5173`.

**Требования:**
- Node.js 20+ или Bun 1.1+
- Современный браузер

## ❓ Часто задаваемые вопросы

**Сайт не обновляется после правок — что делать?**
Откройте диалог Publish и нажмите **Update**. Фронтенд требует
ручного обновления публикации.

**Можно ли убрать бейдж «Built with Lovable»?**
Да, в настройках публикации (доступно на платных тарифах).

**Как экспортировать код?**
В Lovable → GitHub → подключите репозиторий и синхронизируйте.

**Куда писать, если что-то сломалось?**
- Документация: https://docs.lovable.dev
- Discord-сообщество: https://discord.gg/lovable
